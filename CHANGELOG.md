## Baseline Audit Findings (`2026-11-15`, Pre-Remediation `b609475`)

### Critical / P0 (Security, Crashes, False Outputs & Integrity)
- **P0-1 (`Issue #1` / Invoice Reconcile False Positive)**: `extractAmountList` and `/api/miner/invoice-reconcile` treat bare numeric IDs (e.g., `reference 48291`) as monetary amounts and return `reconciled: true` instead of `reconciled: null, status: "insufficient_evidence"`. `evaluateMinerAgreement` also fails to validate boolean `reconciled`, `discrepancy`, and positive `wasmScore`.
- **P0-2 (`screenSanctions` / `fuzzyNameMatch` False OFAC Freezes)**: Bare `0.85` substring matching (`t.includes(q) || q.includes(t)`) without corporate stop-token stripping or `"LAST, First"` normalization causes `AIA Group Limited` to falsely trigger an OFAC freeze (`0.7222`) and broad substring false positives (e.g., `Ali`), while legitimate OFAC entities (e.g., `Viktor Bout`) need reliable positive matching.
- **P0-3 (`evaluateDocumentEndpoint` Crash & SSRF / Auth Gaps)**: `/api/miner/doc-authenticity?signedQrAmount=100` throws live `HTTP 500` when `pdfFaceAmount` is missing; `hasPositiveMarker` NL auto-pass and unbacked 64-hex auto-pass bypass genuine verification; `isSafePublicHttpUrl` lacks DNS resolution validation (`dns.lookup`) and redirect blocking (`redirect: 'manual'`), risking SSRF; streaming cap (5 MB) and `req.destroy()` in `readJsonBody` on overflow are needed.
- **P0-4 (Empty-Body Fallbacks & `po-verify` Edge Cases)**: Silent `SAP SE` / `INV-2026-081` empty-body fallbacks mask invalid/missing inputs instead of returning `400` / `insufficient_evidence`; `/api/miner/po-verify` needs required `approval_cap` (unless explicit math mode), numeric bounds, clearer negative amount errors, and dual evaluation of both line-item and summary math when both exist.
- **P0-5 (`/api/audit/buy`, `buy_x402`, Spend Guard & `diligence-pack`)**: Unbounded/duplicate `selectedIntents` allow wallet drain; `X-Forwarded-For` header spoofing bypasses rate limiting; `diligence-pack` count mismatch (`17` vs `16`) and preview mode stamping Tesla Nov 12 tx across unrelated HK/SG/GB/DE entities; `buy_x402` sequential execution causes Vercel `504` timeouts instead of bounded concurrent `Promise.allSettled` + explicit error reporting.
- **P0-6 (Premature `#461` Hype, `btn-agent-sim` Bug, XSS Hygiene & Monitoring)**: `public/index.html` and `README.md` claim `#461 PASS (81.33%)` even though Devnode rejected `#461` (`7/15 = 46.7% < 70%` floor due to single-template synthetic pairs); `btn-agent-sim` double-JSON-encodes `api()` options (`{ method, headers, body }`), reads wrong fields instead of `checks.*` / `buyRes.items`, hardcodes `invCents`, ignores failed checks/sanctions, uses wrong `.badge.*` classes, and needs `/^https?:\/\//i` validation on external links; missing `/api/health` and `/api/status`; `scripts/deep-audit.mjs` checks HTTP 200 on `/api/wasm/461` without validating `activation_status`/`eval_score`.
