Praman Documentation

Deterministic Pre-Signature Clearing & Audit Infrastructure

Praman sits between autonomous AI agents or procurement workflows and settlement signatures. Rather than trusting free-form LLM text when funds move, Praman computes deterministic line-item math, checks 19,629 OFAC SDN entries in RAM, inspects Solana Token-2022 TLV extensions, and issues EIP-191 signed memos verifiable independently at /verify.

01 / System Topology

Repo-Grounded Architecture

Generated and validated against live source paths (src/handlers.mjs, comparator/comparator.wasm, packages/praman-sdk/solana.js, src/certificate.mjs).

02 / Trade Assurance Escrow

Alibaba & Cainiao 3-Way Math Reconciliation

Compare PO commitments against inspection receipts (POST /api/trade-assurance/audit). On partial conforming deliveries such as PO-ALI-9021 (80 conforming units accepted vs 100 billed), the WASM comparator halts unauthorized full release and routes cleanly to prorated disbursement ($80,000.00 released / $20,000.00 refunded).

03 / Pre-Signature SDK

Solana Spend Guard & Token-2022 Inspection

Available in packages/praman-sdk/solana.js: screens legacy and v0 VersionedTransaction instructions before wallet signing.

  • Inspects Token-2022 TLV Type 12 (PermanentDelegate), TLV Type 14 (TransferHook), and active FreezeAuthority traps.
  • Maintains an in-loop runningSessionSpend accumulator so multi-instruction splits cannot exceed session caps.
  • Halts fail-closed on unresolvable Address Lookup Tables (ALTs) and hijacked prototype hooks.
04 / Multi-Agent Verification

Two-Mind FX Check & Tencent #01 / #03 Claim Audit

Cross-checks quoted currency conversions against ECB/spot references (/verify?case=minds-fx-divergence catches inverted rates such as EUR/USD inversion) and verifies agent-generated claims via POST /api/agent/verify-output (halting unverified IBANs, lapsed LEIs, or synthetic supplier domains).

05 / Deterministic Scoring

651-Byte WebAssembly Comparator

Compiled AssemblyScript module in comparator/comparator.wasm (also exposed at /comparator/comparator.wasm). Exports imw_alloc(size) and imw_score_deterministic(truth: i64, miner: i64, spec_ptr: usize) -> i64 returning 0..10000 basis points across Exact (0), AbsTol (1), RelTol (2), and PassFail (3).

08 / Security & Pricing

Threat Model Coverage

  • Mitigated: Sub-cent floating-point drift (WASM i64 bps), multi-transfer session cap splitting (atomic accumulator), Token-2022 PermanentDelegate clawbacks, unresolved ALT opaque instructions, OFAC SDN alias hits, and inverted currency conversion quotes.
  • Explicitly Out of Server Custody: Praman does not custody private buyer treasury keys on public endpoints. Verification memos sign using the configured resolver attestation key for cryptographic auditability.
09 / Operational Boundaries

Honest Live Limits

  • Batch endpoint /api/evaluator/sanctions-batch caps at 50 entries per stateless POST request.
  • On Vercel serverless functions, /api/pilot-inquiry returns a stateless acknowledgment unless durable storage webhooks are attached (storageMode is reported transparently in the JSON response).
  • All on-chain smart contract references resolve against Ethereum Sepolia and Solana Devnet.
